## ❓ 常見疑問

**Q：「唯一鍵」勾選跟不勾差在哪？**  
A：勾了之後 kintone 會自動防止重複，例如 `role_id` 勾唯一鍵後，你不可能新增兩筆相同的角色代碼。**強烈建議勾**。

**Q：空白欄位的「元素 ID」要怎麼設定？**  
A：拉一個「空白欄位」到表單，點齒輪 → 設定中有「元素 ID」欄位，填 `chain_preview`。這是給 JS 用 `kintone.app.record.getSpaceElement('chain_preview')` 抓取的 key。

**Q：群組選擇欄位（GROUP_SELECT）要怎麼建？**  
A：表單編輯器左側欄位列表 → 找到「群組選擇」（不是「組織選擇」也不是「使用者選擇」）→ 拉到表單 → 設定為「單選」。

**Q：HR/IT 權限怎麼設？要不要建 kintone 角色？**  
A：建議直接用 kintone 既有的「群組」做權限管理。在 App 設定 → 存取權限 → 加入「HR 群組」給編輯權限、其他人唯讀。

**Q：要不要設 API Token？**  
A：Phase 0 不需要。後續 P4 核心引擎開發時，如果有跨 App 查詢的需求才考慮。預設使用「使用者登入身份」即可。

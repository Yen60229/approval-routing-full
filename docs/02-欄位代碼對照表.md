## App 1 — 角色定義表 `role_definition`

**App ID**：**685**

| # | 欄位代碼 | 顯示名稱 | 類型 | 必填 | 唯一鍵 | 預設值 | HR 可見 | 說明 |
|:-:|---------|---------|------|:----:|:------:|--------|:-------:|------|
| 1 | `role_id` | 角色代碼 | 文字（單行） | ✓ | ✓ | （程式產生） | ✗ | 自動產生格式 `ROLE_xxx` |
| 2 | `role_name` | 角色名稱 | 文字（單行） | ✓ | | | ✓ | 例：研發課課長 |
| 3 | `holder_type` | 簽核者類型 | 單選按鈕 | ✓ | | 指定群組 | ✓ | 選項：指定群組 / 指定個人 |
| 4 | `holder_group` | 簽核者（群組） | 群組選擇 | 條件 | | | ✓ | holder_type=群組時必填 |
| 5 | `holder_user` | 簽核者（個人） | 使用者選擇 | 條件 | | | ✓ | holder_type=個人時必填 |
| 6 | `next_role_id` | 下一關角色代碼 | 文字（單行） | | | | ✗ | 由程式提供下拉 UI |
| 7 | `is_chain_end` | 是否為終點 | 核取方塊 | | | 不勾 | ✓ | 選項：「是終點」 |
| 8 | `signing_mode` | 簽核模式 | 單選按鈕 | ✓ | | 任一人簽 | ✓ | 選項：任一人簽 / 全員會簽 |
| 9 | `is_active` | 啟用狀態 | 核取方塊 | | | 勾選 | ✓ | 選項：「啟用中」 |
| 10 | (空白欄位) | 簽核鏈預覽 | 空白欄位 | | | | ✓ | 元素 ID = `chain_preview` |

### 版面建議

```
[role_name (寬度 70%)]              [is_chain_end] [is_active]
[holder_type (寬度 30%)]
[holder_group (寬度 50%)]           [holder_user (寬度 50%)]
[signing_mode (寬度 30%)]
[next_role_id (隱藏，由程式提供下拉 UI)]
[空白欄位 chain_preview (寬度 100%)]
[role_id (寬度 30%，程式用，由 JS 隱藏)]
```

## App 2 — 員工起點對照表 `employee_entry`

**App ID**：**686**

| # | 欄位代碼 | 顯示名稱 | 類型 | 必填 | 唯一鍵 | 預設值 | 說明 |
|:-:|---------|---------|------|:----:|:------:|--------|------|
| 1 | `employee` | 員工 | 使用者選擇（單選） | ✓ | ✓ | | 該員工的「起點」 |
| 2 | `entry_role_id` | 起點角色 | 文字（單行） | ✓ | | | 由程式提供下拉 UI |
| 3 | `is_active` | 啟用狀態 | 核取方塊 | | | 勾選 | 選項：「啟用中」 |

### 版面建議

```
[employee (寬度 50%)]               [is_active (寬度 20%)]
[entry_role_id (隱藏，由程式提供下拉 UI 顯示為「起點角色」)]
```

## 共用子表格 — `approver_chain`（嵌入各申請 App）

| 子表格欄位 | 類型 | 說明 |
|----------|------|------|
| `step_no` | 數值 | 第幾關 |
| `role_id` | 文字（單行） | 該關角色 ID（給程式用） |
| `step_name` | 文字（單行） | 顯示名稱 |
| `expected_signers` | 使用者選擇（多選） | 期望簽核者（介面顯示用） |
| `signed_by` | 使用者選擇（單選） | 實際簽核者（簽完才填，可空） |
| `signed_at` | 日期時間 | 簽核時間（可空） |

## 群組命名規範（給 IT 參考）

| 命名規則 | 範例 |
|---------|------|
| `g_<部門縮寫>_<職級>` | `g_rd_section_head`（研發課課長群組） |
| | `g_rd_dept_head`（研發部部長群組） |
| | `g_finance_vp`（財務副總群組） |

> 群組名稱（顯示用）可中文：「研發課課長」、「研發部部長」  
> 群組代碼（程式用）必須英文：`g_rd_section_head`

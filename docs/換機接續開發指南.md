# 換電腦時怎麼接著做

換一台電腦繼續開發，照下面做就好。

---

## 1. 確認電腦上有這些

- Git
- Node.js（跑測試用）
- Claude Code 桌面版，用同一個帳號登入

## 2. 拿到最新的程式

第一次在這台電腦上用：

```bash
git clone https://github.com/Yen60229/approval-routing-full.git
cd approval-routing-full
npm install
```

之後每次開工前：

```bash
git pull origin main
```

拉下來先跑一次測試，確認環境沒問題：

```bash
npm test
```

## 3. 開新對話時貼這段

Claude Code 的對話紀錄只存在原本那台電腦，換機後是空的，這是正常的。
所有設計決定都寫在文件裡，讀完就能接上。開新對話時貼：

```
我從另一台電腦繼續開發 kintone 簽核路由引擎。

請先讀：
1. CLAUDE.md
2. docs/對話脈絡.md
3. docs/Phase進度追蹤.md

讀完告訴我：現在做到哪、下一步要做什麼、有沒有需要我補充的。
```

## 4. 做完一段就推上去

```bash
git add .
git commit -m "feat: 簡單寫做了什麼"
git push origin main
```

回到另一台電腦時，記得先 `git pull`，避免兩邊改到同一個地方。

# 換機接續開發指南

> 換電腦或跨裝置繼續開發時，照這份文件操作即可無縫接手。

---

## Step 1：確認環境

確認新電腦已安裝：
- [ ] Git
- [ ] Claude Code 桌面版（同帳號登入）
- [ ] Node.js（若未來有 build 工具需求）

---

## Step 2：取得最新程式碼

**第一次使用這台電腦**（尚未 clone）：
```bash
git clone https://github.com/Yen60229/approval-routing-full.git
cd approval-routing-full
```

**之後每次開工前**：
```bash
cd approval-routing-full
git pull origin main
```

---

## Step 3：開啟 Claude Code 並貼上以下提示

打開 Claude Code，把下面這段完整貼進對話框：

```
我從另一台電腦繼續開發 kintone 簽核路由引擎。

請依序讀完以下檔案進入專案脈絡：
1. CLAUDE.md（專案規範）
2. docs/對話脈絡.md（設計決策前因後果）
3. docs/Phase進度追蹤.md（當前進度）

讀完後告訴我：
1. 當前 Phase 與狀態
2. 下一步具體要做什麼
3. 有無需要我補充的資訊

然後繼續開發。
```

---

## Step 4：開工後的工作流程

### 做完一個段落 → 推上 GitHub
```bash
git add .
git commit -m "feat/fix/docs: 簡述做了什麼"
git push origin main
```

### 換回另一台繼續 → 拉下來
```bash
git pull origin main
```

---

## 重要提醒

| 事項 | 說明 |
|------|------|
| 對話記錄不同步 | Claude Code 對話存在本機，換機後對話會是空的，這是正常的 |
| 不需重新解釋 | 所有設計決策都在 `docs/對話脈絡.md`，Claude Code 讀完即可接手 |
| App ID 已固定 | 角色定義表 **685**、員工起點對照表 **686**，已寫入 `core/01-config.js` |
| 每次開工先 pull | 避免兩台電腦產生衝突 |

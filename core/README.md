# core/　共用模組

每個 App 都會載入的模組，寫一次、到處用。檔名前面的數字是編號，**不是載入順序**，實際順序看下面。

| 檔案 | 做什麼 |
|------|--------|
| `01-config.js` | App ID、欄位代碼、狀態名稱等設定，全部集中在這裡 |
| `02-api-client.js` | 呼叫 kintone REST API，附快取（角色表整包快取 5 分鐘） |
| `03-chain-builder.js` | 核心引擎：從員工的起點角色一路往下走，算出整條簽核鏈 |
| `04-utils.js` | 共用小工具：`safeHandler`、SweetAlert2 包裝、送出錯誤彙整 |
| `05-vendor.js` | 確認 SweetAlert2 有載入，沒有的話退回瀏覽器原生的提示框 |
| `06-route-engine.js` | 依表單路由設定（736）一段一段展開簽核鏈 |
| `07-role-picker.js` | 可打字搜尋、依單位分組的下拉元件，只管畫面 |
| `08-directory.js` | 讀 kintone 後台的使用者、組織、職務資料 |
| `09-tool-registry.js` | 把各支工具的按鈕收成列表頁上的四個選單 |

## 載入順序

固定是 `01 → 05 → 04 → 02 → 03 → 06 → 07 → 08 → 09`，每個 App 只放用得到的。
各 App 完整的上傳順序（包含 apps、tools）以 `docs/10-工具按鈕盤點與分組.md` 第四節為準。

要記得的幾條：

- `01` 一定第一個，其他模組都要讀設定
- `03` 要在 `06` 前面，`06` 會用到 `03` 的函式
- `07` 要在 `apps/*/03` 和 `apps/form-route/01` 前面
- `09` 要在所有 `tools/*` 前面
